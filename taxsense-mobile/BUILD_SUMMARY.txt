GETTING STARTED
================================================================================

Installation
  1. cd taxsense-mobile
  2. npm install
  3. npm install -g expo-cli
  4. Copy .env.example to .env
  5. Update environment variables

Development
  1. npm start (start Expo server)
  2. npm run ios (iOS simulator)
  3. npm run android (Android emulator)
  4. npm run web (web browser)

Testing
  1. npm test (run all tests)
  2. npm run test:watch (watch mode)
  3. npm run test:coverage (coverage report)
  4. npm run lint (code linting)
  5. npm run type-check (TypeScript check)

Building
  1. eas build --platform ios (iOS build)
  2. eas build --platform android (Android build)
  3. eas submit --platform ios (iOS submission)
  4. eas submit --platform android (Android submission)
